# Contributing

Thanks for considering a contribution to Dr Watson.

## Getting started

1. Clone the repo and copy `.env.example` to `.env`.
2. Run `npm install`, then `npm run typecheck` and `npm test` to verify the setup.
3. Create a branch for your change off `main`.

## Making changes

- Follow the existing code style.
- Add or update tests for new behavior.
- Run `npm run typecheck` and `npm test` before opening a pull request.
- Keep changes small and focused on one issue.

## Pull requests

Open a draft PR describing what changed and why. A maintainer will review and merge.
